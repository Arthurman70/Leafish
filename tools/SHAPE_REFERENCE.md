# Generate local Minecraft 1.21.1 block shapes

`generate_shapes.py` reproduces the collision and selection data used by the
experimental vanilla local session. The repository contains the generator source
only. Supply your own original Minecraft server archive and official mappings;
keep the generated directory outside the checkout.

Requirements: Python 3.11 or newer, a Java 21 JDK with `java` and `javac`, and the
unmodified `blocks.json` generated by `generate_vanilla_reference.py` from the
same vanilla 1.21.1 server. No Minecraft installation, running server, saved world,
mod loader, or network access is needed during shape generation.

## Inputs and commands

Use the original bundled [Minecraft 1.21.1 server archive](https://piston-data.mojang.com/v1/objects/59353fb40c36d304f2035d51e7d6e6baa98dc05c/server.jar)
and [official 1.21.1 server mappings](https://piston-data.mojang.com/v1/objects/03f8985492bda0afc0898465341eb0acef35f570/server.txt).
The helper does not download them. Supply the bundled `server.jar`, rather than
an extracted inner server, a remapped archive, or a modded distribution.

First generate the ordinary vanilla reference reports, if you do not already
have them. Both output directories below must be new. Paths are examples to
replace with your own; quoted paths also work on Windows.

```text
python tools/generate_vanilla_reference.py --server-jar /path/to/server.jar --java /path/to/jdk-21/bin/java --output /path/to/local-reference

python tools/generate_shapes.py --server-jar /path/to/server.jar --mappings /path/to/server.txt --blocks /path/to/local-reference/generated/reports/blocks.json --java /path/to/jdk-21/bin/java --javac /path/to/jdk-21/bin/javac --output /path/to/local-shapes
```

Omit `--java` and `--javac` when Java 21 is on `PATH`. On Windows, their paths can
end in `java.exe` and `javac.exe`.

The successful output directory contains:

- `shapes-v1.json`: the catalog consumed by the client’s `--shape-catalog` option.
- `summary.json`: input, output, and generator SHA-256 hashes and verification counts.
- `generator.log`: compiler and reference-runtime diagnostics.
- `classes/` and `reference/`: compiled helper classes and the listed server/library
  files extracted into this new directory.

Inputs are read only. Extraction uses the bundle’s explicit file lists, checks
their SHA-256 hashes and path containment, and limits file sizes. The helper runs
Minecraft’s registry bootstrap and shape methods, without invoking the server
entry point or opening a world. Existing output directories are refused. A failed
run leaves its fresh directory and log available for diagnosis; choose another
new directory after fixing the failure.

## Exact provenance

The helper deliberately pins these original reference bytes. A mismatch stops
before Java is run; a matching version label alone is insufficient.

| Input | SHA-256 |
| --- | --- |
| Original bundled server JAR | `e3bc55693e93cda0188f2e60aea28113fc647c5e85a15fa3d1b347349231b4bb` |
| Inner server JAR listed by the bundle | `c301de10f575027d13eac18c7f34409d60648cf56a35d566aa1f530ff617840a` |
| Original official server mappings | `9d0b04bead421c8229aff14b534432bbc927bea642e7c8593d1276b8df8ba53f` |
| Unmodified generated `blocks.json` | `0dde7f869588905763ea6ff2e7e01bec1db740a58d27477fd27c2f07fb029f73` |

Mojang’s version metadata identifies the bundled server by SHA-1
`59353fb40c36d304f2035d51e7d6e6baa98dc05c` and its mappings by SHA-1
`03f8985492bda0afc0898465341eb0acef35f570`. The SHA-256 values above additionally
bind the exact local generation inputs. Preserve the original mapping file and
catalog bytes; reformatting their contents changes their digest.

`ShapeReference.java` resolves original obfuscated class and member names using
those mappings. It enumerates `BuiltInRegistries.BLOCK` states, obtains IDs through
`Block.getId`, and compares every ID, block name and property value with
`blocks.json`. Shape boxes come from the original `VoxelShape.toAabbs` methods,
with no geometry inferred from resource-pack models.

The verified reference has 26,684 block states. Collision shapes are resolved for
26,473 states and selection outlines for 26,379. Generation checks these counts
as well as the complete state identity domain. The schema-v1 report produced by
the tested generator has SHA-256
`f9a7b337abea76a482063e3922b23a78f069e1e20aa40964cff455cfc13b50a1`.
Each run records its actual report hash separately.

## Schema and support limits

The report is a JSON object with `schema_version: 1`, `minecraft_version: "1.21.1"`,
`block_catalog_sha256`, `official_server_sha256`, `official_server_mappings_sha256`,
`generator`, `collision_resolved`, `outline_resolved`, and a dense `states` array.
Entry `states[n]` has `id: n`; the loader must still validate its exact name and
properties against the supplied catalog.

| State field | Meaning |
| --- | --- |
| `id`, `name`, `properties` | Exact numeric state identity, resource name and string-valued properties. |
| `dynamic` | Original block’s `hasDynamicShape()` result. |
| `has_offset` | Original state’s `hasOffsetFunction()` result. |
| `collision` | Collision AABB array, or explicit `null` when unresolved. |
| `outline` | Selection AABB array, or explicit `null` when unresolved. |
| `collision_unresolved`, `outline_unresolved` | Reason string for the corresponding `null`, otherwise explicit `null`. |

Each box has six finite numbers in block-local units:
`[minX, minY, minZ, maxX, maxY, maxZ]`. Extents are preserved, including fence
collision boxes reaching 1.5 blocks high. An empty array means a resolved empty
shape; `null` means unresolved and must never become air or a guessed cube.

For non-dynamic states, the generator compares Minecraft’s cached collision
shape with a direct method call. The direct call uses context objects that throw
on world or player-context queries. Outlines are also rejected when the state has
a position-dependent offset. Dynamic states remain unresolved before either
method is queried.

These deliberate exclusions include moving pistons, shulker boxes, scaffolding,
powder snow and some offset plants. Fluid collision queries and held-item-dependent
light-block outlines also remain unresolved. Other execution failures cause
validation to fail instead of being accepted as an ordinary unresolved case.

This is a static vanilla shape reference. It does not implement dynamic block
behavior, entities, fluids, complete player physics, NeoForge, or mod shapes. It
does not establish gameplay or server parity. Resource packs can change visual
models without changing these server collision shapes.

Run source-only helper checks with:

```text
python -B tools/test_generate_shapes.py
```

The full reference generation command above is the integration check. It requires
the original inputs, which are intentionally absent from the repository.
